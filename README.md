# 潜入工作員

見張りと監視カメラの視界をかいくぐり、指定された物を回収して脱出する、見下ろし型の潜入ゲームです。全十作戦で、最後は巨大戦車との決戦になります。

ブラウザだけで動きます。`index.html` を開けば遊べます。

## 遊び方

- 見張りの扇形の視界に入ると、頭上のゲージがたまります。満タンになると発見され、作戦は失敗です
- 普通に歩くと足音が出て、近くの見張りが寄ってきます。忍び足なら足音は出ません
- 青い点線で囲まれた暗がりで立ち止まれば、すぐそばの見張り以外には見つかりません
- 見張りの背後に回れば、素手で絞め落とせます。消音拳銃は弾数に限りがあります
- 回収物をすべて集めると、脱出地点が開きます

## 操作

| 操作 | パソコン | スマートフォン |
|---|---|---|
| 移動 | WASD または矢印キー | 画面下の左側を触って動かす |
| 忍び足 | Shift を押している間 / C で切り替え | 「忍び足」ボタン |
| 絞め落とす（最終作戦では爆薬の設置） | Space | 「絞め落とす」ボタン |
| 射撃 | F | 「射撃」ボタン |
| 音の切り替え | M | 右上の「音」ボタン |
| 一時停止 | Esc | 「一時停止」ボタン |

## 補足

- 音楽と効果音はすべてその場で合成しているため、音声ファイルはありません
- クリアした記録はブラウザに保存されます
